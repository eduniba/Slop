Esercizio 3 — Piano, Retta e Distanza

Trascina per ruotare • Scorri per zoomare

Testo: Dati A=(1,0,1), B=(2,1,0), C=(0,2,1) e P=(1,1,3).
(a) Equazione cartesiana del piano π per A, B, C

Vettori direttori: AB = (1, 1, -1), AC = (-1, 2, 0).
Vettore normale: n = AB × AC = (2, 1, 3).
Piano π: 2(x - 1) + 1(y - 0) + 3(z - 1) = 0
π : 2x + y + 3z - 5 = 0

(b) Appartenenza di P e retta r ⊥ π per P

Sostituendo P(1,1,3) in π: 2(1) + 1 + 3(3) - 5 = 7 ≠ 0 ⇒ P ∉ π.
La retta r ha direzione n = (2, 1, 3):
r : { x = 1 + 2t, y = 1 + t, z = 3 + 3t }

(c) Intersezione Q = r ∩ π e distanza d(P, π)

2(1+2t) + (1+t) + 3(3+3t) - 5 = 0 ⇒ 14t + 7 = 0 ⇒ t = -1/2.
Proiezione ortogonale: Q = (0, 1/2, 3/2) = (0, 0.5, 1.5).
Distanza: d(P, π) = ||PQ|| = √(1 + 0.25 + 2.25) = √14 / 2 ≈ 1.87
